# Future features

M4 promotes verified Level and School stats from the product requirements into a planned milestone; see [m4-plan.md](m4-plan.md). Remaining features are candidates, not commitments, until evidence and requirements are added to the relevant spec.

1. Broader world/location mapping and reviewed image assets.
2. Optional tray UI, startup launch behavior, installer/update channel, and diagnostics UI.
3. Additional reliable character/game stats selected through configuration or UI.
4. macOS/Linux product support and packaging. Linux runtime discovery and Discord IPC have been smoke-tested, but Windows remains the initial supported product OS.
5. Multiple clients/characters, language/localization support, and richer presence layouts.

Character Name parsing/publishing remains a separate candidate because the default privacy behavior needs an explicit product decision.

Not planned without a new product decision: memory inspection, game injection/modification, credential collection, remote telemetry, or launching Wizard101 from the RPC tool.
