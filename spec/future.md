# Future features

These are candidates, not commitments. Promote a feature into a milestone only after evidence and requirements are added to the relevant spec.

1. Verified level, school, and character-name parsing from logs or another permitted, reliable local source.
2. Broader world/location mapping and reviewed image assets.
3. Optional tray UI, startup launch behavior, installer/update channel, and diagnostics UI.
4. Additional reliable character/game stats selected through configuration or UI.
5. macOS/Linux support if the game log source and Discord IPC behavior can be verified on those platforms.
6. Multiple clients/characters, language/localization support, and richer presence layouts.

Not planned without a new product decision: memory inspection, game injection/modification, credential collection, remote telemetry, or launching Wizard101 from the RPC tool.
